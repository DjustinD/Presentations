# Department Seminar

## Presentation

Open or share the interactive slides:

<https://djustind.github.io/Presentations/DepartmentSeminar/Seminar_Slides.html>

The presentation embeds several local chart and bibliography pages. Keep the HTML, CSS, JavaScript, and data files in this folder together for the slides and standalone demos to work. Use the published HTTPS link, or serve this folder through a local web server; opening the HTML directly from disk can block data requests.

The other HTML files in this folder are standalone visualizations and supporting pages. The seminar slides are not linked from the `kishkay.ca` homepage. The published GitHub Pages link is public and unlisted, not private.
