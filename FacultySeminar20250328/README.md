Open or share the interactive slides:

<https://djustind.github.io/Presentations/FacultySeminar20250328/Seminar_Slides.html>

`Seminar_Slides.html` is the presentation entry point. It uses the local
stylesheet and script, embeds chart files and supporting pages, and links to
the bibliography in `../DepartmentSeminar/`. Keep both seminar folders in the
same repository location so that bibliography link continues to work.

This folder also contains standalone chart demos and their data files. They are separate from the main slides. `presentation.html` is an older alternate deck with unresolved placeholder-image URLs; use `Seminar_Slides.html` as the shareable entry point.

The seminar is not linked from the `kishkay.ca` homepage. Its GitHub Pages URL is public and unlisted, not private. Use the published HTTPS link, or serve the repository through a local web server; opening HTML directly from disk can block data requests.
