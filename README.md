## Hosting

These pages are currently served from this repository's GitHub Pages site at `djustind.github.io/Presentations/`. The `www.kishkay.ca` site is hosted separately, and the seminar URLs under that domain currently return 404. Publishing the pages under `kishkay.ca` would require adding them to that site's hosting or deployment setup; this repository does not change the existing site.

The pages are static HTML, CSS, JavaScript, SVG, and CSV files. There is no build step. Keep each presentation's supporting files in place: the slides embed local pages and visualizations, and those pages load their local data. Open the published HTTPS links (or serve the repository through a local web server); opening HTML files directly from disk can prevent browser data requests from working.

See each presentation folder's README for its entry point and contents.
